> Здравствуйте! Отправляю тестовое задание «Сервис для поиска поставщиков продуктов питания».
>
> **Прототип:** https://goulash.svyatoslav-reshetnikov.ru (вход по логину и паролю, пришлю отдельно)
> **Репозиторий:** https://github.com/svyatoslav-reshetnikov/goulash-tech-suppliers
>
> **Что это.** Пользователь выбирает продукт (например, «Моцарелла») и город или регион России, при желании с соседними регионами. ИИ-агент (YandexGPT и Яндекс Поиск) находит сайты поставщиков, читает разделы их сайтов (контакты, о компании, доставка, прайс, сертификаты) и собирает карточки: контакты, адрес, чем занимаются, регионы, условия доставки, минимальный заказ, цены, сертификаты. У каждого факта есть дословная цитата и ссылка на страницу; выдуманные данные код отклоняет. Поставщики ранжируются (оценка 0–100 с объяснением и меткой «в вашем регионе / доставляет / в соседнем / неизвестно»), лучшие помечены «Рекомендуем связаться» и показывают вопросы для звонка, есть сравнение поставщиков и заметки.
>
> **Формат.** Веб-приложение: Python (FastAPI), React, Postgres, Docker Compose. Монолит, потому что нагрузки нет, а агент выделен чистым модулем и при необходимости выносится в воркер. Справочник из 176 категорий построен по меню «Сушкоф и пицца» (по ТЗ) и зафиксирован в репозитории.
>
> **Честные ограничения.** Если поставщик не публикует цены, минимальный заказ или сертификаты на сайте, поле остаётся пустым с пометкой «не найдено на сайте», а ИНН находится не у всех; каждый запуск поиска платный (обычно 40–70 ₽), поэтому на стенде стоят лимиты (10 запусков в сутки). Подробности и результаты проверок в README и docs/SPEC.md.
>
> Для проверки без трат можно открыть вкладку «Справочник» и выбор локации. Запуск поиска занимает 2–4 минуты: агент подробно изучает сайты.

## Что проверено и как

- Чистая сборка и запуск через `docker compose` без ключей: приложение поднимается, справочник категорий (176) загружается из репозитория.
- 194 автоматических теста (162 без базы данных); запуск агента на заглушках и четыре реальных запуска с YandexGPT по категории «Моцарелла» (Казань); последний — с полным изучением сайтов.
- Развёрнуто на VPS: HTTPS по домену, вход по паролю (без пароля 401), CI/CD (тесты, сборка образов, выкладка по push в main).
- Не проверено: 2GIS (нет ключа), поиск по другим категориям и регионам.
